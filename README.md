# Avisomo Organization Configuration
This repository contains organization-wide community health files and configurations for GitHub.

## Contents
* **Pull Request Template**: Located in `.github/pull_request_template.md`. This template is automatically applied to all repositories within the Avisomo organization to ensure consistent tracking with Azure DevOps (AvisomoAS).

## How to use
Standard templates defined here are inherited by all other repositories. To override a template in a specific project, create a local version within that repository's `.github/` folder.
